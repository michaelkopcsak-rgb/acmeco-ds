# acmeco-ds

**Prototype · AcmeCo is a fictional brand.**

A working model of an AI-ready design system: design tokens, about 40 accessible React components, Storybook and a Figma library, all generated from this repo. It comes with the governance that lets an AI coding agent build with the system, and propose changes to it, without drifting from it.

The aim is a way of working that depends less on drawing screens by hand in Figma and more on ideating with production code: screens and prototypes are assembled from real components, and the design system is the contract that keeps them consistent.

## What's in it

| | |
|---|---|
| **Tokens** (`tokens/`) | DTCG JSON in three tiers (primitives → semantic → component), built into CSS variables. Each token's description says what it's for and where its value came from (an evidence label). Every text and UI colour pair is checked for WCAG AA. |
| **Components** (`src/components/`) | React + TypeScript on React Aria. Each has a guidance file (when to use, when not to, accessibility, content), stories, a states matrix and interaction tests with axe. |
| **Storybook** | Foundations (colour, type, shape, icons, motion, contrast) read straight from the token files, and every component with its docs. |
| **Figma library** | Variables in three collections, text and effect styles, icons and component sets bound to the component variables, generated by `scripts/figma/` and checked against the rendered code for parity. |
| **The AI usage layer** | A generated catalogue of every component (`docs/catalog.json`), a screen-building guide and a Claude Code skill, and boundary checks that keep agent-built screens to the system. |
| **Governance** (`docs/GOVERNANCE.md`) | What an agent may do alone, what needs a designer's approval, and the checks that catch drift. |

## Run it

Needs the Node version in `.nvmrc`.

```bash
npm install
npm run storybook   # component workshop on http://localhost:6007
```

Checks, as CI runs them:

```bash
npm run lint && npm run typecheck
npm run check:tokens && npm run check:contrast && npm run check:boundaries
npm run catalog
npm test
```

Other scripts: `npm run tokens` (rebuild the CSS variables), `npm run figma:payload` and `npm run figma:components` (prepare the Figma sync), `npm run changeset`.
